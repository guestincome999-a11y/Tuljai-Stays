## Final QA Pass

- Confirm every route redirects unauthenticated users to `/login`.
- Confirm denied roles see the permission-denied panel.
- Confirm all destructive or sensitive controls require confirmation and/or reason.
- Confirm no page exposes tokens, raw stack traces, or secrets.
- Confirm all documentation limitations match current backend capability.

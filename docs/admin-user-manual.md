# Admin User Manual

## Logging In

1. Open the Admin Panel.
2. Enter the registered admin phone number.
3. Request OTP and verify it.
4. If the account has admin access, the dashboard opens automatically.

## Dashboard Overview

Use the dashboard for live operational status, pending bookings, live owners, lodge health, announcements, and quick action entry points.

## Live Operations

Open Live Operations to monitor booking pressure, QR scans, owner availability, emergency announcements, and operational queues.

## Booking Intervention

Open Bookings to search and filter booking records. Open a booking detail page to inspect guest privacy, owner response deadline, manual accept/reject controls, call workflow foundation, escalation foundation, and transfer foundation.

## Calling Owner Or Pilgrim

Use the booking detail call controls. Contact details are only shown to roles with operational booking permission.

## Manual Booking Actions

Manual status updates require permission, a reason, and confirmation. The backend still validates status transitions.

## Lodge Governance

Use Lodges, Verification, Owners, Rooms, and Photo Review to manage lodge readiness. Lodge detail shows address, room, photo, amenity, verification, and readiness signals.

## Photo Approval

Open Photo Review to approve clear lodge media or reject unsafe/irrelevant photos with a reason.

## Settings And Feature Flags

Use Settings and Feature Flags to manage public app configuration, booking timers, QR TTL, payment/WhatsApp toggles, maintenance messages, and rollout foundations.

## Festival Mode

Festival Control manages festival mode, banner text, advisory text, dates, support instructions, and festival UI foundation.

## Emergency Mode

Emergency Control manages booking pause, emergency mode, maintenance mode, QR availability, emergency messages, and emergency announcements.

## Monitoring And Health

Use System Health, API Health, Notifications Monitor, QR Monitor, Security, Sessions, Backups, and Audit to check platform health and incident signals.

## Analytics And Reports

Use Executive BI, Analytics, Revenue, Performance, and Exports for business metrics. Revenue requires finance permission.

## Logout And Session Safety

Use Logout from the top bar when leaving the workstation. Session inventory and remote revocation require future backend endpoints.

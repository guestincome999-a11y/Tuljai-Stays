# Customer Support Playbook

## Response Time Targets

| Severity                | Target First Response |
| ----------------------- | --------------------- |
| Pilgrim arrival blocked | 5 minutes             |
| Booking status issue    | 15 minutes            |
| Owner operational issue | 15 minutes            |
| General question        | 4 business hours      |

## Booking Issue

1. Confirm booking code and phone number through approved support process.
2. Check booking status in admin.
3. Contact owner if pending or overdue.
4. Escalate to operations owner if arrival is near.
5. Record outcome.

## QR Issue

1. Confirm booking is accepted and QR is active.
2. Ask pilgrim to refresh QR in app.
3. Ask owner to retry scan with good brightness/network.
4. Escalate to technical owner for repeated failures.
5. Use manual fallback only with operations approval.

## Owner Unavailable

1. Call owner.
2. Check alternate staff contact if available.
3. Escalate overdue booking to operations owner.
4. Use admin intervention if approved.

## Wrong Lodge

1. Confirm booking lodge.
2. Confirm owner scanning account.
3. If pilgrim reached wrong location, provide correct lodge guidance.
4. Escalate if reassignment is needed.

## Room Unavailable

1. Confirm accepted booking and room status.
2. Contact owner immediately.
3. Escalate to operations owner.
4. Offer approved reassignment or support path.

## Late Check-In

1. Confirm booking status.
2. Confirm owner availability.
3. Ask pilgrim to keep QR ready.
4. Escalate if owner is unreachable.

## Festival Crowd

- Provide calm, clear guidance.
- Avoid promising availability without owner confirmation.
- Use announcements for broad crowd or availability notices.

## Technical Issue

- Record device, app, time, booking code if relevant, and screenshot if available.
- Escalate to technical owner for repeated or blocking issues.

## Complaint Handling

- Acknowledge issue.
- Record facts.
- Do not assign blame before review.
- Escalate safety, payment, or identity issues immediately.

## Escalation Path

Support executive -> Support owner -> Operations owner -> Business owner or incident commander.

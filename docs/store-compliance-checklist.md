# Store Compliance Checklist

## Play Store Readiness

- [ ] Privacy policy URL is public and accurate.
- [ ] Support email is valid.
- [ ] App category selected.
- [ ] Store descriptions reviewed.
- [ ] Screenshots captured from staging data.
- [ ] Feature graphic created.
- [ ] App icon uploaded.
- [ ] Data safety form completed.
- [ ] Account deletion process documented.

## Permissions

- [ ] Owner camera permission explains QR scanning.
- [ ] Notification permission explains booking and QR updates.
- [ ] Vibration usage is limited to owner booking alerts.
- [ ] Pilgrim app does not request camera unless a future feature needs it.
- [ ] Location permission is not requested unless a future feature needs it.

## Data Safety

- [ ] Phone number usage documented.
- [ ] Booking and guest data usage documented.
- [ ] Device token usage documented.
- [ ] QR scan data usage documented.
- [ ] Photo moderation described for lodge photos.
- [ ] Support data usage documented.

## User-Generated Content

- [ ] Lodge photos are moderated.
- [ ] Reviews/reporting policy is documented before public review features launch.
- [ ] Unsafe or inaccurate photo rejection process exists.

## Other Compliance

- [ ] Child safety review completed.
- [ ] Payment disclosure added if payments are enabled later.
- [ ] Government ID handling reviewed if identity document features expand.
- [ ] Legal/business owner approves final policy and terms.

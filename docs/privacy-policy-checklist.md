# Privacy Policy Checklist

This is a checklist for legal and business review. It is not final legal advice.

## Data Collection Topics

- [ ] Phone number collection for OTP login
- [ ] Booking details
- [ ] Guest details
- [ ] Guest identity document handling, if used
- [ ] Lodge owner data
- [ ] Device tokens for notifications
- [ ] Notification delivery logs
- [ ] QR check-in and scan logs
- [ ] Location data if added later
- [ ] Lodge and room photos
- [ ] Analytics and operational reports
- [ ] Support contact data
- [ ] Admin audit logs

## User Rights and Operations

- [ ] Data retention periods
- [ ] Data deletion request process
- [ ] Account deletion process
- [ ] Support contact information
- [ ] Data sharing with lodge owners after QR verification
- [ ] Service providers such as Firebase, Supabase, Render, and PostgreSQL hosting
- [ ] Security controls and sensitive data exclusions

## Store Requirements

- [ ] Public privacy policy URL
- [ ] Data safety form alignment
- [ ] Contact email
- [ ] Review by legal/business owner before launch

# Tuljai Stays Release Notes v1

## Backend v1 Summary

- OTP and JWT authentication foundation
- Roles and sessions foundation
- Lodge, owner, room, and photo backend core
- Booking engine and availability locking
- Secure pilgrim-safe QR payload and owner scan flow
- Guest register and checkout foundation
- Notifications, realtime events, announcements
- Reviews, analytics, reports, settings, backups foundation
- Security, performance, deployment, and QA readiness documentation

## Pilgrim App v1 Summary

- Login and session foundation
- Home and lodge discovery
- Lodge details and booking request flow
- My bookings and booking lifecycle
- Scannable QR pass for approved bookings
- Notifications, announcements, live updates, and offline-friendly states

## Owner App v1 Summary

- Owner login and navigation
- Dashboard and booking alerts
- Accept/reject booking actions
- QR scanner and secure check-in
- Guest register and checkout flows
- Room management, notifications, and operational reports

## Admin Dashboard v1 Summary

- Admin authentication and RBAC foundation
- Live operations center
- Booking control center
- Lodge, owner, room, verification, and photo governance
- Platform control, settings, feature flags, emergency/festival controls
- Monitoring, security, BI, analytics, and release readiness docs

## Known Limitations

- Final brand artwork is not committed.
- Store screenshots still need staging capture.
- Legal privacy policy and terms require business/legal review.
- Production support phone/email must be confirmed.
- Mobile store builds require EAS/store setup.
- Payment and WhatsApp integrations remain optional/future.

## Testing Requirements

- Complete QA sign-off report.
- Test QR scan on physical owner device.
- Test push notifications with production-capable credentials.
- Validate staging deployment before production.

## Production Readiness Status

The software foundation is production-readiness oriented, but public release is blocked until final assets, legal copy, support contacts, store metadata, staging QA, and production environment checks are complete.

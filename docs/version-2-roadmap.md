# Version 2 Roadmap

## Version 1.1

- Add CI smoke tests for backend health, auth, booking, QR, settings, and admin login.
- Add production rate limiting for public and auth-adjacent endpoints.
- Add EAS build profiles and mobile store build numbers.
- Add final app icons, splash screens, notification icons, and store screenshots.
- Add admin audit read API and session inventory/revocation APIs.
- Add owner app public feature flag/settings consumption.
- Add signed upload URL flow with MIME and size validation.
- Add Redis Socket.IO adapter readiness behind configuration.

## Version 1.5

- Add export jobs and scheduled report delivery.
- Add WhatsApp Business API as an optional provider.
- Add email notification automation.
- Add settlement and commission workflows.
- Add owner analytics dashboards.
- Add housekeeping and maintenance task module.
- Add customer support ticketing and CRM foundations.
- Add stronger observability: traces, structured logs, uptime alerts, security alerts.
- Add materialized analytics summaries for high-volume festival periods.

## Version 2.0

- Add online payments and refund workflows.
- Add dynamic pricing and festival demand controls.
- Add AI demand prediction and occupancy forecasting.
- Add loyalty and pilgrim account history features.
- Add web booking portal.
- Add multi-language expansion for Marathi, Hindi, and English.
- Add multi-city expansion beyond Tuljapur.
- Add advanced lodge onboarding, KYC, and compliance workflows.
- Add full owner revenue settlement and reconciliation.
